Chronos Scripting Engine

Exhaustive Guide to the Modular OP System (v9.5)

1. Core Architecture

DSP Graph, Compilation, and Topology

Chronos compiles all script logic into a **Directed Acyclic Graph (DAG)** of **cr_node** objects. This is a purely functional dataflow model. Every node represents one operation (OP), constant, or variable access.

Compilation includes a **Topological Sort** (build_exec_list) to determine the exact, sample-accurate execution order (exec_order), guaranteeing that a node runs only after all its inputs have been computed.

Execution Flow (Per-Sample)

Audio Callback
→
cr_tick() (Time++)
→
Execute exec_order nodes
→
Read out node value (L/R)
→
Output Sample
Hot-Swapping and State Continuity

Live-coding is achieved via a two-context system (active and back).

  1. New script compiles into the back context.
  2. **State Migration:** migrate_dsp_state copies the DSP state (buffers, phases, envelope stages) from the old active nodes to the corresponding new back nodes, matching by variable name.
  3. The contexts are atomically swapped using a thread lock.

**Crucial:** Stateful operations (like adsr, phasor, delay) must be fed by variables whose names remain unchanged to preserve continuity upon hot-swap.

2. Chronos Scripting Language (CRL)

Basic Syntax and Operators

CRL supports standard algebraic operators that are directly mapped to DSP nodes:

  • **Arithmetic:** + (add), - (sub), * (mul), / (div), % (mod)
  • **Comparison:** == (eq), != (ne), > (gt), < (lt), >= (ge), <= (le)
  • **Logical:** && (and), || (or)
A = B * (C + 1.0) # Algebraic operators for standard math
condition = time > 10.0 && bpm == 120.0 # Operators for comparison/logic

Note on Conditional Flow Logic:

While operators like $\text{&&}$ and $\text{||}$ work within expressions, for clarity and guaranteed compilation within complex if statements or nested logic, using the explicit function calls (e.g., and, gt) is often recommended to enforce the exact DSP graph structure and ensure proper operand grouping.

Macros (def / return) and Scoping

Macros are syntactic sugar for inlined code blocks. Arguments are pass-by-reference to the corresponding input nodes. Local variables defined inside the macro body are scoped with a unique prefix to prevent collisions.

def SawtoothFilter(pitch, cutoff) {
    f = mtof(pitch)
    saw = sub(mul(phasor(f), 2.0), 1.0)
    return filter(saw, 1.0, cutoff, 10.0)
}
out = SawtoothFilter(NOTE_PITCH, 800.0)
Conditional Logic (if / else)

Provides sample-by-sample dynamic signal routing. Variables modified inside the blocks are reconciled at the end using the implicit OP_SELECT node (Phi function).

pan = 0.0 # Center
cond = time > 5.0 # Simple comparison using the operator
if (cond) {
    pan = 0.8 # Pan Right
} else {
    pan = -0.8 # Pan Left
}
# 'pan' is now a merged node selecting between 0.8 and -0.8

3. DSP Operations (Reference)

Sources, Timing, and Control

phasor(f): Saw phase ramp (0→1). **Stateful**.

sine(p): Sine wave output (-1→1).

noise(): White noise output (-1→1).

rhythm("pat"): Pattern gate (1/0). **Static Buffer**.

seq(T, v1, ...): Step sequencer/pattern reader.

time: Global time in seconds.

bars: Global position in musical bars (relies on bpm).

mtof(m): MIDI Note → Frequency (Hz).

Filters, Dynamics, and Shapers

adsr(g, A, D, S, R): ADSR Envelope. **Stateful**.

filter(s, t, c, Q): SVF. **Stateful**. $\text{t}=0$ BP, $1$ LP, $2$ HP.

peakeq(s, f, g, Q): Peaking EQ (BiQuad).

hpf(s, c): Simple 1st-order High Pass Filter.

delay(s, t, fb): Delay Line (Cubic interp). **Stateful**.

reverb(s, d, dmp, m): FDN Reverb. **Stateful/Buffer**.

compress(s, th, r): Dynamics Compressor.

limit(s): Fast Peak Limiter (0.95 thresh).

tanh(s): Soft clip ($\tanh(x)$).

fold(s, th): Wavefolding distortion.

clip(s): Hard clip ($\pm 1.0$).

Calculus, State Logic, and Mapping

slew(s, r): Slew Limiter (Portamento). **Stateful**.

diff(s): Calculates $x[n] - x[n-1]$ (Edge Detection).

integrate(s, r): Accumulator/Integrator. **Stateful**.

sah(s, t): Sample and Hold (on rising edge). **Stateful**.

map(v, min1, max1, min2, max2): Linear scaling.

lerp(a, b, t): Linear Interpolation.

clamp(v, min, max): Limits value range.

Math and Bitwise Operations

floor(x), ceil(x), abs(x), sign(x), sqrt(x), exp(x), log(x), atan2(y, x).

bitand(a, b), bitor(a, b), bitxor(a, b), bitnot(a), bitshl(a, b), bitshr(a, b): Integer context ops.

5. Tutorials and Snippets Library

Foundational Elements: Phase, Rhythm, and Sequence

T0: The Phasor and Phase Accumulation

The phasor is the time source for all periodic signals. It is a **stateful** integrator that accumulates phase from 0.0 to 1.0 based on the input frequency ($\text{f}$).

Phase Flow (Oscillation)

Input Freq (Hz)
→
phasor(f)
→
Phase (0.0 → 1.0)
→
sine(p) / abs(p)
p = phasor(440.0) # Produces phase for 440 Hz (A4)
A4_sine = sine(p) 
out = A4_sine * 0.5
T9: Rhythmic Pattern Arrays and Gates (rhythm)

The rhythm function takes a string literal, which is compiled into a static buffer (an array of 1.0 for 'x' and 0.0 for '-'). This array is read sequentially by $\text{time}$ and $\text{bpm}$.

The sequence length is derived from the string length, and the step duration is $\frac{1}{BPM \times 4 / N}$, where $N$ is the number of steps in a bar (usually 16 or 32 for common patterns).

bpm = 120
# 8-step pattern (2 beats at 1/8 resolution)
pattern_8th = rhythm("x-x-x-x-")
# 16-step pattern (4 beats at 1/16 resolution)
pattern_16th = rhythm("x-xx-x-x-xx-x-x-") 

noise_hit = noise() * adsr(pattern_16th, 0.001, 0.05, 0.0, 0.0)
out = noise_hit
T10: Step Sequencing and Pitch Arrays (seq)

The seq function reads step values over time. Its first argument ($\text{T}$) is the duration of each step in seconds. Subsequent arguments are the values (nodes) to be sequenced.

# T = 0.25 seconds per step (Quarter Note at 120 BPM)
step_time = 0.25 
sequence_notes = seq(step_time, 60.0, 62.0, 64.0, 67.0) # C4, D4, E4, G4

# Gate on every step (uses the same step time to align)
gate = adsr(rhythm("x---x---x---x---"), 0.01, 0.1, 0.5, 0.1) 

freq = mtof(sequence_notes)
out = sine(phasor(freq)) * gate
T11: Polyphony and Mode Switching

Chronos supports pseudo-polyphony by managing multiple independent signal chains. When MONO_MODE is set to $0.0$ (via `poly` command), you typically manage several $\text{adsr}$ instances and merge the outputs.

**Tip:** Use macros to encapsulate each voice's DSP chain for clean polyphonic implementation.

def Voice(pitch, gate) {
    f = mtof(pitch)
    e = adsr(gate, 0.01, 0.2, 0.8, 0.1)
    return sine(phasor(f)) * e * 0.3
}

voice1_pitch = 60.0 
voice2_pitch = 67.0 
voice3_pitch = 72.0 

out = Voice(voice1_pitch, rhythm("x---")) + \
        Voice(voice2_pitch, rhythm("--x-")) + \
        Voice(voice3_pitch, rhythm("----")) # Add voices to master output
T12: Combining Rhythms for Complex Grooves

Logical operators can combine different rhythmic rhythm nodes (which output 0 or 1) to create polyrhythms or fill patterns.

kick_pat = rhythm("x---x---")
snare_pat = rhythm("----x---")
hihat_pat = rhythm("x-x-x-x-")

# The hi-hat and kick should NOT overlap, use bitwise XOR (^).
anti_hat = hihat_pat ^ kick_pat
kick_gate = adsr(kick_pat, 0.001, 0.1, 0.0, 0.0)
hat_gate = adsr(anti_hat, 0.001, 0.01, 0.0, 0.0)

out = limit(
    kick_gate * 0.8 + 
    snare_pat * 0.5 + 
    hat_gate * 0.3 * hpf(noise(), 5000.0)
)

Tutorials: Core DSP Patterns

T1: Simple Monophonic Synth (MTOF & ADSR)

Minimal setup for a playable monosynth: using $\text{mtof}$ to convert pitch, driving a sine oscillator, and applying an ADSR envelope via $\text{NOTE\_GATE}$.

bpm = 130
freq = NOTE_PITCH > 0 ? mtof(NOTE_PITCH) : 0.0 # Use operator for simple conditional calculation
env = adsr(NOTE_GATE, 0.01, 0.5, 0.5, 0.2)
tone = sine(phasor(freq))
out = tone * env # Using multiplication operator
T2: Rhythmic Looping and Filtering

Creating a pulsing sound using the $\text{rhythm}$ generator and shaping the output with an $\text{SVF}$.

bpm = 120
pat_trigger = rhythm("x---x-x-")
click_env = adsr(pat_trigger, 0.001, 0.08, 0.0, 0.05)
pulse_sig = noise() * click_env # Using multiplication operator

# Low-Pass Filter (type 1.0) at 100Hz with resonance (0.8)
filtered_sig = filter(pulse_sig, 1.0, 100.0, 0.8)

out = filtered_sig * 1.5
T3: FM Synth and Wavefolding

Demonstrates Frequency Modulation (FM) using macros and applying the aggressive $\text{fold}$ distortion.

def fm_op(carrier_freq, mod_sig, mod_amt) {
    mod_freq = carrier_freq + mod_sig * mod_amt
    return sine(phasor(mod_freq))
}

freq_base = mtof(NOTE_PITCH)
env_amp = adsr(NOTE_GATE, 0.1, 0.9, 0.7, 0.5)
mod_sig = fm_op(freq_base * 4.0, 0.0, 0.0) # Modulator at 4x base freq
fm_out = fm_op(freq_base, mod_sig, freq_base * 5.0) # FM Index 5.0 * base freq

folded = fold(fm_out, 0.5)
out = folded * env_amp
T4: Slew-Limited Wobble Bass

Using $\text{slew}$ to smooth a high-frequency LFO sweep controlling a filter, creating the characteristic "wobble" effect.

freq_base = mtof(NOTE_PITCH)
saw = map(phasor(freq_base), 0, 1, -1, 1)

lfo_mod = UnipolarLFO(8.0, 300.0, 3000.0) # Fast 8Hz cutoff sweep range
slew_rate = 10000.0 # Slew limit applied to the LFO modulation
smooth_lfo = slew(lfo_mod, slew_rate)

env_amp = adsr(NOTE_GATE, 0.005, 0.1, 1.0, 0.1)

filt_out = filter(saw, 1.0, smooth_lfo, 20.0) # High Q (20.0) LP filter

out = limit(filt_out * env_amp)
T5: Song Arrangement (Bar-Based Switching) - Using Operators

Using operators ($\text{>=}$, $\text{<}$, $\text{&&}$) for bar-based song section control.

bpm = 128
sig_bass = sine(phasor(55.0)) * 0.5
mix_amt = 0.0

# Section 1: Bars 0.0 to 8.0
if (bars < 8.0) {
    is_active = rhythm("x---") > 0.5
    if (is_active) { mix_amt = 0.8 }
}

# Section 2: Bars 8.0 up to 12.0 (Breakdown)
if (bars >= 8.0 && bars < 12.0) {
    mix_amt = 0.0
}

# Section 3: Bars 12.0 onwards
if (bars >= 12.0) {
    is_active_fast = rhythm("x-x-") > 0.5
    if (is_active_fast) { mix_amt = 1.0 }
}

out = sig_bass * mix_amt
T6: Portamento (Pitch Glide)

Use the slew operator on the discrete NOTE_PITCH signal before MTOF conversion.

glide_rate = 150.0 
smooth_pitch = slew(NOTE_PITCH, glide_rate)
freq = mtof(smooth_pitch)
env = adsr(NOTE_GATE, 0.01, 0.2, 0.8, 0.1)
out = sine(phasor(freq)) * env
T7: LFO with Sample & Hold Quantization

Use $\text{sah}$ to freeze LFO values on rhythmic trigger, creating stepped random modulation.

lfo_source = UnipolarLFO(0.1, 200.0, 5000.0) # Slow LFO
trigger = phasor(4.0) # 4Hz (every quarter note) trigger
stepped_mod = sah(lfo_source, trigger)

out = filter(sig_in, 1.0, stepped_mod, 5.0)
T8: Basic Distortion Chain (Tanh → Fold)

Combine soft clipping and wave folding for aggressive harmonic generation.

sig_in = SAWTOOTH_WAVE * 2.0 # Boost for more distortion
soft_clipped = tanh(sig_in)
folded_out = fold(soft_clipped, 0.6)
out = folded_out * 0.5

def BipolarLFO(rate, depth) {
    return sine(phasor(rate)) * depth
}

def UnipolarLFO(rate, min, max) {
    bipolar = sine(phasor(rate))
    return map(bipolar, -1, 1, min, max)
}

    return lerp(sig_in, d, mix)
