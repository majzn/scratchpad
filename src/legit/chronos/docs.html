1. C API Functions

2. Scripting Language Syntax

2.1 Variables and Output

  • **Assignment:** `variable_name = expression` [cite: uploaded file: chronos.h]
  • **Comments:** Use `#` for single-line comments. [cite: uploaded file: chronos.h]
  • **Global Time:** Use the reserved variable `time` to get the current time in seconds (read-only). [cite: uploaded file: chronos.h]
  • **Output:** Set audio outputs using `out` or `output.0` (Left) and `output.1` (Right). [cite: uploaded file: chronos.h]

2.2 Macros (`def` / `return`)

Macros are statically expanded functions for code reuse.

def fm_osc(carrier_freq, modulation_amount) {
    return sine(phasor(carrier_freq) + sine(phasor(modulation_amount)))
}

output.0 = fm_osc(440, 100) * 0.5

4. Code Snippets

Easily copy-pasteable examples for common tasks.

4.1 Simple Synth Voice

# Sine wave with an envelope triggered every 0.25 seconds
beat = 60.0 / 120.0 # 120 BPM
gate = seq(beat / 4, 1, 0, 0, 0) # Hits every 16th note
env = adsr(gate, 0.01, 0.5)

freq_val = mtof(60) # C4
lfo = sine(phasor(0.1)) * 5 # Slow, wide vibrato

output.0 = sine(phasor(freq_val + lfo)) * env * 0.4

4.2 Rhythmic Noise Gate (Hi-Hat)

# Open and close a high-hat every 8th note
beat = 60.0 / 100.0
hat_gate = seq(beat/2, 1, 0)
hat_env = adsr(hat_gate, 0.005, 0.1)

# Use High-Pass Filter (type 2) to shape the noise
output.0 = filter(noise() * hat_env, 2, 6000, 0.8) * 0.2
